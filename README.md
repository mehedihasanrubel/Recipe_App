# 🍳 Recipe App

A feature-rich Flutter application for discovering, saving, and managing cooking recipes in real time.

Built with **Flutter, Firebase, and Provider**, the app provides recipe discovery, smart ingredient scaling, favorites, weekly meal planning, and dynamic Dark/Light theme support.

## 🌟 Key Features

* 🔥 **Real-time Firestore Integration** — Dynamic recipe, category, and ingredient data.
* 🔎 **Recipe Filtering** — Filter recipes by meal type such as Breakfast, Lunch, and Dinner.
* 📅 **Weekly Meal Planner** — Organize recipes into daily and weekly meal plans.
* 🧮 **Smart Ingredient Scaler** — Automatically adjust ingredient quantities based on serving size.
* ❤️ **Favorites** — Save and manage favorite recipes with instant UI feedback.
* 🌙 **Dark/Light Theme** — Dynamic theme switching using Provider state management.

## 🛠️ Tech Stack

* **Flutter (Dart)** — Cross-platform mobile application
* **Provider** — State management
* **Firebase Cloud Firestore** — Real-time database
* **Firebase Cloud Storage** — Recipe image storage
* **Git & GitHub** — Version control

## 🚀 Getting Started

### Clone the repository

```bash

cd Recipe_App
flutter pub get
flutter run
```

> Firebase configuration is required to run the project locally.
