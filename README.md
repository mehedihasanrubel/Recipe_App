## 🌟 Key Features

* **Real-time Firestore Integration:** Dynamic fetching of recipe collections, categories, and ingredients.
* **Dynamic Recipe Filtering:** Instant filtering by meal type (Breakfast, Lunch, Dinner).
* **Interactive Meal Planner:** Organize daily and weekly meal plans with instant database synchronization.
* **Smart Ingredient Scaler:** Dynamic ingredient quantity calculation based on user-selected serving sizes.
* **Optimistic UI Favorites:** Zero-latency bookmarking for immediate UI feedback.
* **Dark/Light Dynamic Theme:** Flexible theme switching using `Provider` state management.

---

## 🛠️ Tech Stack & Architecture

* **Frontend Framework:** Flutter (Dart)
* **State Management:** Provider
* **Cloud Database:** Firebase Cloud Firestore
* **Media Storage:** Firebase Cloud Storage
* **Version Control:** Git & GitHub
